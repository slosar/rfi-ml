# ML RFI Characterization

This repository is the RFI ML code for BMX. Contains:
 * ae_g.ipynb: Main notebook for running RFI characterization
 * rfi_ml.py Version for testing on synthetic timestreams with injected RFI
 * rfi_bmx.py Version for running on BMX sky observations
 * rfi_ml_new_train_each_epoch.py Old testing version using different train scheme, deprecated.
